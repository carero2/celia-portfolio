# celia muntaner — portfolio website

The site follows the Canva deck exactly: one section per Canva page (1–27), in the same order, with the
text placed at the same position, size and weight as in Canva. Backgrounds are the Canva exports of the
copy **"portfolio WEB - fondos sin texto (no editar)"** (same pages, same crops, text removed).

```
index.html   the website (generated by build.py — edit texts in build.py and run: python build.py)
fonts/       Inter, hosted with the site
images/N.jpg Canva page N without text
media/N.mp4  Canva page N as video (compressed for the web) + N-poster.jpg
```

- Videos 5, 11, 17 play silently and have a "sonido" button. Videos 19 and 20 have no audio at all.
- Page 23 = Vimeo 760811572, page 25 = YouTube CMqaot85DZw (embedded players).
- On phones, each page's image/video is shown first and its text below, so it stays readable.

## Publish on GitHub Pages
1. github.com → New repository (public) → upload **everything in this folder** (index.html, fonts, images, media).
   Do not upload the big original videos (they are kept in *celia-portfolio-originales-canva*).
2. Settings → Pages → Deploy from a branch → `main` / root → Save. Live in ~1 minute.
3. Own domain: Settings → Pages → Custom domain (e.g. celiamuntaner.com), then at your registrar add
   A records 185.199.108.153 / 109.153 / 110.153 / 111.153 and a CNAME `www` → YOUR-USER.github.io.
